# 土釘邊坡設計試算

土釘邊坡（土釘擋土牆）的網頁試算工具。可以切換公噸制（t、t/m²、kgf/cm²）或 SI 制（kN、kPa、MPa），電腦、平板、手機都能用。計算基礎是原 Excel「soil nailing(0828).xlsx」的「BREAK OUT _MODIFY A」工作表，修正了原表的錯誤，並補上外部穩定、面版、整體穩定與施工階段檢核。

純前端靜態網頁，不需要建置或安裝任何套件。

## 功能

- **土釘型式**：可選鑽孔灌漿式（π·D<sub>DH</sub>·q<sub>u</sub>，附 GEC 7 表 4.4 握裹強度參考值）或打入式（鋼筋周長 × σ'v × tan δ，即原 Excel 方法）。
- **地下水**：常時水位與暴雨（高水位）分開輸入。需求拉力取兩者中的大值；整體穩定分別檢核。可以勾選「面版排水良好」，土釘需求拉力就不計水壓。
- **內部穩定（逐支）**：
  - Rankine 土壓依各排負擔高度積分（也可切回原 Excel 點值法）
  - 鋼筋抗拉
  - 沿土釘方向計算 Rankine 破壞面外的有效錨定長度，再檢核拉拔
- **面版**：GEC 7 的釘頭拉力 T<sub>o</sub>、撓曲 R<sub>FF</sub>、穿孔剪力 V<sub>F</sub>。
- **外部穩定**：加勁體滑動，常時與暴雨兩種工況。
- **整體穩定**：圓弧搜尋，方法可選簡化 Bishop、Spencer、Morgenstern-Price（半正弦）。
  - 計入土釘抗力
  - 工況包含完工常時、完工暴雨、逐階開挖
  - 斷面圖畫出臨界圓弧，並列出土釘交點的力和切片明細
  - 完工常時臨界圓弧另外附三種方法比較
- **安全係數**：依規範自動帶入，可選《建築物基礎構造設計規範（112）》、《水土保持技術規範》、FHWA GEC 7（2015），或自訂。每個數值都註明出處。
- **案件儲存**：存在瀏覽器（localStorage），可匯出、匯入 .json 備份檔。
- **匯出 Word 計算書**：內容包含設計條件、分析方法、逐支檢核與算例、面版、滑動、整體穩定（附斷面圖）、結論與備註。
- 支援深色模式。

## 整體穩定分析說明

- 滑動面為圓弧，切成 40 片。Spencer 與 Morgenstern-Price 以 GLE 通式求解 λ，同時滿足力矩平衡與力平衡。
- 土釘可發揮力取下列三者的最小值，除以水平間距換算成每公尺寬，作用在滑動面交點、方向沿土釘：
  - 後段拉拔
  - 鋼筋抗拉
  - 面版抗力 + 前段拉拔
- 土釘抗力可選容許值（除以構件 FS）或標稱值；作用方式可選被動（除以 FS）或主動。
- 搜尋限制：出口在牆趾或牆趾前方的開挖面，入口在牆頂後方的地表。圓心格網 24 × 24（施工階段 16 × 16），每個圓心 8 種半徑，最後兩次局部加密。
- 驗證：
  - ACADS 1(a) 基準例題（解答 FS ≈ 1.00）：Bishop 0.985、Spencer 0.984、M-P 0.984
  - 含土釘的臨界圓弧另以 Python 獨立重算，誤差 0.14%

## 相對原 Excel 的修正

1. 鋼筋周長 28.7π = 90.16 的單位是 mm，原表當作 cm 再除以 100，拉拔阻抗被放大 10 倍。
2. 最下排的負擔高度原本只算到 9.4 m，9.4～10 m 的土壓沒有分配給任何一排。
3. 拉拔需求原本用水平分力，現在改用沿土釘的軸力（÷ cos ψ）。
4. 有效錨定長度原本是水平投影近似，現在改成沿土釘與破壞面的實際交點。
5. 正向力 N 原本同一欄混用兩種公式（有一部分多除了周長的一半），現在統一改正。

## 部署到 GitHub Pages

1. 在 GitHub 建立 repository（例如 `soil-nailing`），設為 Public。
2. 上傳 `index.html`、`calc.js`、`app.js`、`README.md`、`.nojekyll`。
3. 進入 **Settings → Pages**。Source 選 **Deploy from a branch**，Branch 選 `main`、資料夾選 `/ (root)`，按 Save。
4. 約 1～2 分鐘後，網址為 `https://<帳號>.github.io/soil-nailing/`。

也可以不部署，直接用瀏覽器打開 `index.html`。

## 限制

- 單一均質土層、水平地下水位、無地震力。只做圓弧滑動面。
- c' = 0 時，施工階段的無支撐開挖面無法自立，FS 會偏低；請依地質資料輸入視凝聚力。
- 本工具供初步設計與自我檢核用，正式送審建議另以商用邊坡軟體核對，並以現場拉拔試驗驗證 q<sub>u</sub>。
